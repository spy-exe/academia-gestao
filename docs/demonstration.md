# Demonstração acadêmica

Acesse https://academia.malha.app com as credenciais fornecidas privadamente. Os dados iniciais são fictícios. Não execute seeds no banco publicado para preparar uma apresentação.

1. Abra Visão geral e observe alunos, professores, planos e indicadores financeiros. Os totais serão atualizados conforme as operações.
2. Crie um plano e um aluno, depois associe o plano ao aluno. Consulte o registro e use a pesquisa para reencontrá-lo.
3. Gere a mensalidade da competência escolhida. Repita a emissão e confirme que o histórico não ganhou uma segunda cobrança. Registre o pagamento administrativo e confira a receita no dashboard.
4. Cadastre um professor. Crie uma ficha para o aluno com dois exercícios, altere a ordem, salve, recarregue e consulte os detalhes.
5. Registre duas avaliações em datas diferentes. Abra o histórico do aluno e alterne as medidas no gráfico. O IMC é descritivo e não oferece diagnóstico.
6. Edite um dado, recarregue a página e confirme persistência. Arquive somente o aluno criado para a demonstração; consulte seu histórico preservado.
7. Repita a navegação numa largura de 390px. Mostre os botões das listas, o menu Mais, os formulários e a preservação do rascunho ao girar a tela.

Os testes automatizados repetem esses fluxos contra banco e API reais, incluindo reinício. Durante a apresentação, use a evidência da release para demonstrar restart, backup e rollback; não reinicie serviços sem uma janela de manutenção.

O projeto pode ser importado pelo `backend/pom.xml` no IntelliJ IDEA com JDK 21. A instituição deve receber a declaração de autoria e assistência exigida por suas regras; o histórico Git registra as alterações reais.
